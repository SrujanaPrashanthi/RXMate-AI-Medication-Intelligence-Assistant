# RxMate AI – Medication Intelligence Assistant

🚀 Overview

This project is an AI-powered healthcare assistant that helps users with prescription understanding, medication tracking, refill reminders, and healthcare-related queries.

🧠 Features

• Prescription assistance  
• Medication tracking  
• Refill reminder support  
• Healthcare query assistance  
• Context-aware responses using RAG

⚙️ Tech Stack

• Python  
• Streamlit  
• LangChain  
• Google Gemini API  
• FAISS

▶️ How to Run

1. Install required libraries
2. Configure Google Gemini API Key
3. Run the application
